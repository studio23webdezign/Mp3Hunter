# VIBE PLAYER — European industrial-tech design system

## Direction
Premium European audio technology: precise, restrained, engineered and editorial. Avoid generic AI dashboard tropes, over-rounded cards, decorative gradients and gold/purple/pink palettes.

## Palette
| Token | Hex | Use |
|---|---|---|
| Obsidian | #0B1017 | App canvas |

## Typography
- Display: Michroma Regular, sparingly for brand marks and short technical labels.
- Interface: Space Grotesk variable for navigation, controls, body copy and headings.
- No bubbly display fonts, faux-futuristic tracking or all-caps for every label.
- Preserve readable hierarchy and accessibility.

## Layout
- 8 dp spacing rhythm; consistent 20–24 dp page gutters.
- Compact 10–16 dp radii; avoid pill-shaped everything.
- Fine cool-grey borders, subtle elevation and selective blue light.
- Let artwork provide colour; keep app chrome quiet.
- No nested-card stacks or generic gradient blobs.
- Prioritise thumb reach, contrast and restrained motion.

## Icons and artwork
- Lucide family, consistent 1.8–2 dp stroke and 20–24 dp controls.
- No emoji or mixed icon packs.
- Music campaign artwork should resemble professional streaming-service advertising: editorial photography, confident composition, realistic headphone styling and controlled colour grading.
- Artwork assets are separate files, not baked into UI screenshots.

## Screen order
1. Dork Search / home
2. Now Playing
3. Local Library
4. Playlists and queue
5. Equalizer
6. Settings and media tools

## Quality gate
Test compact and large phones, loading/empty/error/playing/paused states, accessibility labels and touch targets. Preserve existing Dork Search behavior.

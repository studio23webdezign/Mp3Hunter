# MP3 HUNTER

Android music discovery and offline library app, built with Kotlin and Jetpack Compose.

## Product goals
- Balanced South African and international music discovery (50/50).
- Artist-name correction and alias recognition (for example, “kabza de smal” → “Kabza De Small”).
- Search authorised music sources and show direct MP3 download actions only when the audio URL is verified and downloading is permitted.
- Local favourites, history, queue, player and offline library.

## Status
Project scaffold is being built in staged sprints. Live source integrations, download engine, player and release QA remain future work.

## Stack
Kotlin, Jetpack Compose, Room, OkHttp, AndroidX Media3 and WorkManager.
